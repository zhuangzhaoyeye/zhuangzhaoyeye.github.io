第 39 课：DPO

DPO 即「直接偏好优化」——第 38 课我们为 PPO（近端策略优化）付了「四模型驻留 + 训练不稳定 + 调参难」的代价。这一课换一个问法：如果 RLHF（基于人类反馈的强化学习）的目标函数本来就有闭式解，为什么还要用强化学习一步步去逼近它？DPO 就是把 RL 问题变成「解方程」——反解出隐式奖励、消掉配分函数，最后得到一条可以直接梯度下降的分类损失。

🎯 学完这 6 步你将能够：
① 从 RLHF 最优解反解出隐式奖励 r=β·log(π/π_ref)，并说清 Z(x) 为什么能消去
② 把隐式奖励代进 Bradley-Terry，独立推出 DPO 损失
③ 说清 β 敏感、offline 无探索、可能退化三条缺陷，并知道哪个变体补哪条
🗺 本节推理链（6 步：从"闭式解"到"哪个变体补哪个缺陷"）
1RLHF 的「奖励 − β·KL」目标有闭式解，因为带 KL 约束的最大化可以显式解出 π*，于是反解出隐式奖励 r = β·log(π/π_ref) + β·log Z(x)。
↓
2把隐式奖励代进奖励模型的 Bradley-Terry 目标，因为两个回答作差时 β·log Z(x) 相消，于是RL 退化成一条分类损失，不再需要奖励模型和采样。
↓
3损失里只剩一个 β（KL 惩罚系数）同时管「拟合偏好」和「贴住参考」，因为两头都要它管，因此β 太小学不动、太大梯度饱和——它极敏感。
↓
4DPO 只用固定偏好数据、训练时不自己生成答案，因为探索被整个砍掉，于是学到的上限被数据封死，发现不了数据集之外的更优答案。
↓
5把 DPO 的账算全：β 敏感、仍要参考模型、可能退化，因为损失只看 chosen/rejected 的相对差、不看绝对概率，因此模型可能靠压 rejected 过关、chosen 绝对概率反而掉。
↓
6【支链 · 引出变体族】每条缺陷都有人专门补：IPO 治 β、KTO 治无配对数据、CPO 治遗忘、ORPO/SimPO 删参考模型，因此下一课逐个展开它们的损失。

1
RLHF 要训奖励模型、再跑 PPO，能不能绕过强化学习、直接写出最优策略的公式？
提示：先想 RLHF 在最大化什么（奖励减 KL 惩罚）；再想「带约束的优化」能不能有闭式解。
▾
知识背景
DPO（Direct Preference Optimization，直接偏好优化）由 Rafailov、Sharma、Mitchell、Manning、Ermon、Finn 提出（斯坦福，arXiv:2305.18290，NeurIPS 2023）。当时痛点：RLHF 要分三段（SFT 即监督微调 → 训奖励模型 → PPO），PPO 慢、不稳定、要同时驻留 4 个模型。DPO 的起点是一个数学事实——RLHF 那个「奖励 − β·KL 惩罚」的目标有闭式解，可以反解出奖励。

上一课（第 38 课）我们为 PPO 付了四模型驻留 + 不稳定 + 调参难的代价。DPO 换个问法：如果 RLHF 的目标函数本来就有闭式解，为什么要用强化学习一步步去逼近它？

可以把这类比成爬山：PPO 是「靠反复试错一步步爬到山顶」，DPO 是「把函数直接求导、令导数为零解出山顶」——前者慢但通用，后者快但要求函数有显式解。RLHF 的目标恰好有。

🧮 闭式解 + 反解出隐式奖励
Step 1：RLHF 的最优策略有闭式形式
量式子含义
优化目标max E[r(x,y)] − β·KL(π ∥ π_ref)既要高奖励，又不能偏离参考模型太远
最优解π*(y|x) = (1/Z(x))·π_ref(y|x)·exp(r(x,y)/β)参考分布乘奖励的指数
配分函数Z(x) = Σ_y π_ref(y|x)·exp(r(x,y)/β)归一化常数，让概率和为 1
Step 2：两边取 log 反解出「隐式奖励」
步骤结果
两边取 log 再移项r(x,y) = β·log(π*(y|x)/π_ref(y|x)) + β·log Z(x)
关键观察β·log Z(x) 只跟 x 有关、跟 y 无关——它只是一个常数偏移
这就是「你的语言模型其实是一个奖励模型」：奖励被策略 π 和参考 π_ref 隐式表达出来了，不用再单独训一个奖励模型。
Step 3：用 2 个回答把公式跑一遍（β=1）
量y1y2
π_ref(y)0.40.6
奖励 r(y)1.00.0
π*(y) = π_ref·e^{r/β} / Z0.6440.356
Z(x) = 0.4×e¹ + 0.6×e⁰ = 0.4×2.718 + 0.6 = 1.687；π*(y1) = 0.4×2.718/1.687 = 0.644，π*(y2) = 0.6/1.687 = 0.356。反解：r(y1) = log(0.644/0.4) + log(1.687) = 0.477 + 0.523 = 1.0 ✓——公式自洽。

2
反解出的隐式奖励 r=β·log(π/π_ref)，怎么变成一个能直接梯度下降的损失函数？
提示：先想奖励模型是怎么训的（Bradley-Terry 把「更喜欢」变成概率）；再把隐式奖励代进去，看 Z(x) 去哪了。
▾
知识背景
Bradley-Terry 模型（1952）把「成对比较」变成概率：P(y_w ≻ y_l | x) = σ(r_w − r_l)，奖励模型就是按这个目标训的。DPO 把上一卡反解出的 r = β·log(π/π_ref) + β·log Z(x) 代进去——两个回答作差时 β·log Z(x) 相消，于是奖励差只依赖 π 和 π_ref 的对数概率，训练奖励模型、采样这些步骤全都不需要了。

上一张卡片反解出了隐式奖励。现在把它接进奖励模型的训练目标（Bradley-Terry），惊喜就出现了：那个讨厌的配分函数 Z(x) 在作差时自动消掉。

可以把这类比成比咖啡甜度：两杯咖啡都加了同量的糖（Z(x)），比较谁更甜时糖抵消了，只剩咖啡豆本身（π 对 π_ref）的差异——所以根本不用知道加了多少糖。

🧮 从 Bradley-Terry 到 DPO 损失
Step 1：Bradley-Terry 概率 + 隐式奖励
量式子
更喜欢 y_w 的概率P(y_w ≻ y_l) = σ(r(y_w) − r(y_l))
奖励差（Z 消去后）r(y_w) − r(y_l) = β·[log(π_w/ref_w) − log(π_l/ref_l)]
Step 2：最大化似然 = 最小化负对数
目标式子
DPO 损失L = −log σ(β·log(π_w/ref_w) − β·log(π_l/ref_l))
这就是一条二分类的交叉熵损失：奖励模型、参考模型以外的采样、强化学习，全部消失，只剩策略 π 和参考 π_ref 的对数概率比。
Step 3：数字走查（β=0.1）
量chosen (w)rejected (l)
策略概率 π0.50.2
参考概率 π_ref0.30.4
log-ratio = log(π/π_ref)+0.511−0.693
差值 d = 0.511 − (−0.693) = 1.204；Δ = β·d = 0.1×1.204 = 0.120；σ(0.120) = 0.530；L = −log 0.530 = 0.635。

损失里的 β 参数，为什么取 0.01 和取 1 会差出完全不同的结果？
提示：先想 β 在 RLHF 目标里是 KL 惩罚系数，惩罚越重模型越不敢偏离参考；再看它进损失后对梯度做了什么。
▾
知识背景
β 本是 RLHF 目标「奖励 − β·KL」里的 KL 惩罚系数。DPO 论文（arXiv:2305.18290）在不同 β 下做实验，发现结果对 β 敏感。机制：β 太小 → 惩罚弱 → 模型敢大幅偏离 π_ref → 过拟合偏好标注里的噪声；β 太大 → 惩罚强 → 模型被钉在 π_ref 附近 → 对齐不足。

上一张卡片看到 β 是损失里的温度。它一头管「拟合偏好」，一头管「别偏离参考模型」——两头都要它管，所以特别敏感。

可以把这类比成教练手里的缰绳：松了马乱跑（过拟合噪声），紧了马原地不动（对齐不足）——正好卡在中间一小段才好用。

概率σ(Δ) = 1/(1 + e^{−Δ})
损失L = −log σ(Δ)

β 太小 → σ 停在 0.5 附近（固定 d 时区分度弱）；β 太大 → σ 逼近 1（饱和、梯度消失）。只有中间一小段好用——这就是「β 敏感」的数字真相。注意：这是固定 d 的损失侧视角；真实训练里 β 太小还会削弱 KL 惩罚、表现为过拟合噪声（见知识背景），两者对应 β 的两个角色、并不矛盾。

4
DPO 训练时只用固定的偏好数据集、不自己生成新答案，会失去什么？
提示：先想 PPO 训练时每轮都会从当前策略采样新回答让奖励模型打分；DPO 没有这一步，那「新答案」从哪来？
▾
知识背景
DPO 是 离线（offline）方法：偏好数据集 {prompt, chosen, rejected} 是事先采好的，训练时策略只在固定答案上算概率，不再生成新答案。对比 PPO/GRPO（分组相对策略优化）的 在线（online）：每轮从当前策略采样新回答、用奖励模型/规则打分，能探索到数据集里没有的答案。

上一张卡片看到 β 敏感是「参数」问题。这一张是「数据」问题：DPO 把「探索」这一步整个砍掉了。

可以把这类比成备考：一个学生只做「老师给的真题」（offline），从来不自己生成新答案，那他学到的上限就是这份真题的上限；另一个学生边做题边自己加练（online），可能发现老师没给的更优解法。

🧮 离线 vs 在线：探索空间差多少
Step 1：训练时各自「生成」多少新答案
方法训练时的数据来源新生成的答案数
离线 DPO固定 N 个 prompt × 每 prompt 1 对 (chosen, rejected)0
在线 GRPO每轮从当前策略采样 G 个新回答（G=8~64）每轮 N×G 个
Step 2：上限被数据封死
情形结果
数据集 chosen 的奖励只有 0.5（及格），真正最优是 1.0离线 DPO 只能把策略往 0.5 的方向拉，永远到不了 1.0
在线方法每轮采样有机会采样到接近 1.0 的新答案，把上限顶上去
关键：离线的损失再低，也只证明「模型拟合了这批固定数据」，不证明「模型能产出比数据更好的答案」。探索是提升上限的唯一途径，而 DPO 把它关掉了。

5
DPO 这么简洁，它自己还藏着哪些缺陷？
提示：从三条线索想——β 那关过了吗、参考模型砍了吗、损失只看「相对差」不看「绝对概率」会怎样？
▾
知识背景
DPO 的三个已知缺陷：① β 敏感（Card 3）；② 仍要驻留参考模型 π_ref——策略 + 参考 = 2 个模型，比 PPO 的 4 个少，但仍不是 1 个，省下的显存有限；③ 可能退化（degeneration）——DPO 损失只看 chosen 与 rejected 的 log-ratio 差，不看绝对概率，模型可能同时压低两者的概率来凑差值。

上一张卡片看到探索被砍。现在把 DPO 的账算全：三条缺陷，第三条最反直觉。

可以把这类比成一场比赛：DPO 只要求「冠军必须比最后一名高」，却不要求冠军自己「够快」——选手们可能一起跑慢，只要差距拉开，损失照样下降。

🧮 退化：损失在降，chosen 的绝对概率却在掉
Step 1：正常 → 退化的概率变化
回答训练前概率退化后概率变化
chosen（π_w）0.50.4掉了
rejected（π_l）0.30.1掉得更狠
Step 2：log-ratio 差反而变大
时刻d = log(π_w/ref_w) − log(π_l/ref_l)
训练前log(0.5/0.3) − log(0.3/0.4) = 0.799
退化后log(0.4/0.3) − log(0.1/0.4) = 1.674
损失下降（d 从 0.799 涨到 1.674，σ 变大、L 变小），但 chosen 的绝对概率从 0.5 掉到 0.4——模型更不会说「好话」了。这就是退化：损失只看相对差、不看绝对值，模型可以靠「把 rejected 压得更狠」过关。

知识背景
DPO 之后出现一批变体（第 40 课展开）：IPO（Azar et al., arXiv:2310.12036）用平方损失正则化，缓解 β 敏感；KTO（Ethayarajh et al., arXiv:2402.01306）只需单个回答的好坏、不需配对，处理「无偏好对」数据；CPO（Xu et al., arXiv:2401.08417）加 SFT 正则防遗忘；ORPO（Hong et al., arXiv:2403.07691）把 SFT 和偏好合成一个目标、删掉参考模型；SimPO（Meng et al., arXiv:2405.14734）用序列平均对数概率 + 长度正则、也删掉参考模型。

上一张卡片列了三条缺陷。好消息是：每条缺陷都有人专门补。

可以把这类比成修车：DPO 是一辆「够用但有三处小毛病」的车，后面每一代修一处——换减震（IPO 治 β 敏感）、改油箱（KTO 治数据形态）、拆备胎（ORPO/SimPO 删参考模型）。
