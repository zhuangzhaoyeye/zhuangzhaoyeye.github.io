第 39 课：DPO

DPO 即「直接偏好优化」——第 38 课我们为 PPO（近端策略优化）付了「四模型驻留 + 训练不稳定 + 调参难」的代价。这一课换一个问法：如果 RLHF（基于人类反馈的强化学习）的目标函数本来就有闭式解，为什么还要用强化学习一步步去逼近它？DPO 并不去解出最优策略（里面的配分函数 Z(x) 算不出来），而是做一次变量替换：用策略自己的概率比表示隐式奖励、让 Z(x) 在作差时消掉，把「训奖励模型 + 在线 RL」换成一条仍需梯度下降、但可以直接在偏好数据上训练的分类损失。

🎯 学完这 6 步你将能够：
① 从 RLHF 最优解反解出隐式奖励 r=β·log(π/π_ref)，并说清 Z(x) 为什么能消去
② 把隐式奖励代进 Bradley-Terry，独立推出 DPO 损失
③ 说清 β 失效、离线拿不到新反馈、chosen 概率下降等缺陷，并知道哪个变体针对哪条
🗺 本节推理链（6 步：从"闭式解"到"哪个变体补哪个缺陷"）
1RLHF 的「奖励 − β·KL」目标有闭式解，因为带 KL 约束的最大化可以显式解出 π*，于是反解出隐式奖励 r = β·log(π/π_ref) + β·log Z(x)。
↓
2把隐式奖励代进奖励模型的 Bradley-Terry 目标，因为两个回答作差时 β·log Z(x) 相消，于是RL 退化成一条分类损失，不再需要奖励模型和采样。
↓
3损失里只剩一个 β（KL 惩罚系数）同时管「拟合偏好」和「贴住参考」，因为两头都要它管，因此β 太小允许偏离很远、易过拟合偏好噪声，β 太大一点偏离就饱和、对齐不足；偏好一边倒时 β 甚至挡不住偏离——它极敏感。
↓
4DPO 只用固定偏好数据、训练时不自己生成答案，因为在线采样被整个砍掉，于是训练时拿不到对自己新回答的反馈，好坏只能靠固定数据推断，还要承受数据与当前策略的分布偏移。
↓
5把 DPO 的账算全：β 敏感、依赖参考模型、chosen 概率可能下降，因为损失只看 chosen/rejected 的相对差、不看绝对概率，因此模型可能靠压 rejected 过关、chosen 绝对概率反而跌破参考模型。
↓
6【支链 · 引出变体族】每条缺陷都有变体针对：IPO 让 β 重新起作用、DPOP 防 chosen 概率下跌、CPO/ORPO/SimPO 删参考模型，KTO 另把数据放宽到单条好坏标签，因此下一课逐个展开它们的损失。

1
RLHF 要训奖励模型、再跑 PPO，能不能绕过强化学习、直接写出最优策略的公式？
提示：先想 RLHF 在最大化什么（奖励减 KL 惩罚）；再想「带约束的优化」能不能有闭式解。
▾
知识背景
DPO（Direct Preference Optimization，直接偏好优化）由 Rafailov、Sharma、Mitchell、Ermon、Manning、Finn 提出（斯坦福，arXiv:2305.18290，NeurIPS 2023）。当时痛点：RLHF 要分三段（SFT 即监督微调 → 训奖励模型 → PPO），PPO 慢、不稳定、要同时驻留 4 个模型。DPO 的起点是一个既有结论（原文写「Following prior work … it is straightforward to show」）——RLHF 那个「奖励 − β·KL 惩罚」的目标有闭式解；但原文也指出解里的配分函数 Z(x)「仍然很难估计」，所以 DPO 不去解它，而是用它反解出奖励。

上一课（第 38 课）我们为 PPO 付了四模型驻留 + 不稳定 + 调参难的代价。DPO 换个问法：如果 RLHF 的目标函数本来就有闭式解，为什么要用强化学习一步步去逼近它？

可以把这类比成爬山：PPO 要先造一张地形图（奖励模型），再边走边采样试错；DPO 发现「山顶长什么样」能直接用策略自己的概率比写出来，于是省掉造地图和试错，直接对着偏好数据做梯度下降——仍是一步步走，只是少了两道工序。

🧮 闭式解 + 反解出隐式奖励
Step 1：RLHF 的最优策略有闭式形式
量式子含义
优化目标max E[r(x,y)] − β·KL(π ∥ π_ref)既要高奖励，又不能偏离参考模型太远
最优解π*(y|x) = (1/Z(x))·π_ref(y|x)·exp(r(x,y)/β)参考分布乘奖励的指数
配分函数Z(x) = Σ_y π_ref(y|x)·exp(r(x,y)/β)归一化常数，让概率和为 1
Step 2：两边取 log 反解出「隐式奖励」
步骤结果
两边取 log 再移项r(x,y) = β·log(π*(y|x)/π_ref(y|x)) + β·log Z(x)
关键观察β·log Z(x) 只跟 x 有关、跟 y 无关——它只是一个常数偏移
这就是「你的语言模型其实是一个奖励模型」：奖励被策略 π 和参考 π_ref 隐式表达出来了，不用再单独训一个奖励模型。
Step 3：用 2 个回答把公式跑一遍（β=1）
量y1y2
π_ref(y)0.40.6
奖励 r(y)1.00.0
π*(y) = π_ref·e^{r/β} / Z0.6440.356
Z(x) = 0.4×e¹ + 0.6×e⁰ = 0.4×2.718 + 0.6 = 1.687；π*(y1) = 0.4×2.718/1.687 = 0.644，π*(y2) = 0.6/1.687 = 0.356。反解：r(y1) = log(0.644/0.4) + log(1.687) = 0.477 + 0.523 = 1.0 ✓——公式自洽。
🎯 留下什么问题

目标有闭式解 → 奖励能用策略自身表示，RL 可换成对策略参数的分类损失（仍要梯度下降）；没有闭式解 → 只能先训奖励模型、再用 PPO 在线逼近。下一个问题：反解出的这个 r 里还带着讨厌的 Z(x)，怎么把它变成能直接梯度下降的损失？

2
反解出的隐式奖励 r=β·log(π/π_ref)，怎么变成一个能直接梯度下降的损失函数？
提示：先想奖励模型是怎么训的（Bradley-Terry 把「更喜欢」变成概率）；再把隐式奖励代进去，看 Z(x) 去哪了。
▾
知识背景
Bradley-Terry 模型（1952）把「成对比较」变成概率：P(y_w ≻ y_l | x) = σ(r_w − r_l)，奖励模型就是按这个目标训的。DPO 把上一卡反解出的 r = β·log(π/π_ref) + β·log Z(x) 代进去——两个回答作差时 β·log Z(x) 相消，于是奖励差只依赖 π 和 π_ref 的对数概率，训练奖励模型、采样这些步骤全都不需要了。

上一张卡片反解出了隐式奖励。现在把它接进奖励模型的训练目标（Bradley-Terry），惊喜就出现了：那个讨厌的配分函数 Z(x) 在作差时自动消掉。

可以把这类比成比咖啡甜度：两杯咖啡都加了同量的糖（Z(x)），比较谁更甜时糖抵消了，只剩咖啡豆本身（π 对 π_ref）的差异——所以根本不用知道加了多少糖。

🧮 从 Bradley-Terry 到 DPO 损失
Step 1：Bradley-Terry 概率 + 隐式奖励
量式子
更喜欢 y_w 的概率P(y_w ≻ y_l) = σ(r(y_w) − r(y_l))
奖励差（Z 消去后）r(y_w) − r(y_l) = β·[log(π_w/ref_w) − log(π_l/ref_l)]
Step 2：最大化似然 = 最小化负对数
目标式子
DPO 损失L = −log σ(β·log(π_w/ref_w) − β·log(π_l/ref_l))
这就是一条二分类的交叉熵损失：奖励模型、参考模型以外的采样、强化学习，全部消失，只剩策略 π 和参考 π_ref 的对数概率比。

量chosen (w)rejected (l)

损失里的 β 参数，为什么取 0.01 和取 1 会差出完全不同的结果？
提示：先想 β 在 RLHF 目标里是 KL 惩罚系数，惩罚越重模型越不敢偏离参考；再看它进损失后对梯度做了什么。
▾
知识背景
β 本是 RLHF 目标「奖励 − β·KL」里的 KL 惩罚系数。DPO 论文（arXiv:2305.18290）默认 β=0.1（摘要任务用 0.5），并说明未认真调 β；β 敏感是后续实践与变体论文反复指出的问题。机制：β 太小 → 惩罚弱 → 模型敢大幅偏离 π_ref → 过拟合偏好标注里的噪声；β 太大 → 惩罚强 → 模型被钉在 π_ref 附近 → 对齐不足。

上一张卡片的损失里只剩一个超参 β。它一头管「拟合偏好」，一头管「别偏离参考模型」——两头都要它管，所以特别敏感。

可以把这类比成教练手里的缰绳：松了马乱跑（过拟合噪声），紧了马原地不动（对齐不足）——正好卡在中间一小段才好用。

4
DPO 训练时只用固定的偏好数据集、不自己生成新答案，会失去什么？
提示：先想 PPO 训练时每轮都会从当前策略采样新回答让奖励模型打分；DPO 没有这一步，那「新答案」从哪来？
▾
知识背景
DPO 是 离线（offline）方法：偏好数据集 {prompt, chosen, rejected} 是事先采好的，训练时策略只在固定答案上算概率，不再生成新答案。对比 PPO/GRPO（分组相对策略优化）的 在线（online）：每轮从当前策略采样新回答、用奖励模型/规则打分，能探索到数据集里没有的答案。

上一张卡片看到 β 敏感是「参数」问题。这一张是「数据」问题：DPO 把「探索」这一步整个砍掉了。

可以把这类比成备考：一个学生只看「老师批好的真题」（offline），也许能举一反三写出更好的解法，但没人批改他的新写法；另一个学生边做边交给老师批（online），新写法对不对当场就知道。

🧮 离线 vs 在线：探索空间差多少
Step 1：训练时各自「生成」多少新答案
方法训练时的数据来源新生成的答案数
离线 DPO固定 N 个 prompt × 每 prompt 1 对 (chosen, rejected)0
在线 GRPO每轮从当前策略采样 G 个新回答（G=8~64 为示意；DeepSeekMath 每题采 64 个）每轮 N×G 个
Step 2：上限被数据封死
情形结果
数据集 chosen 的奖励只有 0.5（及格），真正最优是 1.0（示意）离线 DPO 拉大 chosen 与 rejected 的相对差，策略可能泛化出高于 0.5 的回答，但训练中没人给这些新回答打分，好坏全靠泛化
在线方法每轮采样每个新回答都被打分，采到接近 1.0 的答案能被立即强化，采到坏答案也能被立即压下去
关键：离线的损失再低，也只证明「模型拟合了这批固定数据」。DPO 并不是模仿 chosen，原文在 Anthropic-HH 上它的回答就超过了数据里的 chosen；它失去的是对自身新回答的反馈，加上训练数据来自别的策略，分布一偏就没法纠正。在线采样正是持续拿到新反馈的办法，DPO 把它关掉了。
🎯 留下什么问题

5
DPO 这么简洁，它自己还藏着哪些缺陷？
提示：从三条线索想——β 那关过了吗、参考模型砍了吗、损失只看「相对差」不看「绝对概率」会怎样？
▾
知识背景
DPO 的三个已知缺陷：① β 敏感（Card 3）；② 依赖参考模型 π_ref——损失要用 π_ref 的对数概率，默认训练时策略 + 参考同时驻留 2 个模型；因为数据是离线固定的，也可在训练前一次算好缓存（TRL 的 precompute_ref_log_probs，文档写明此时参考模型不必留在显存），但这次前向计算和对 π_ref 的依赖省不掉；③ chosen 概率下降（文献称 likelihood displacement，Razin et al., arXiv:2410.08847；Smaug/DPOP, arXiv:2402.13228 从理论上证明标准 DPO 会出现）——损失只看 chosen 与 rejected 的 log-ratio 差，不看绝对概率，模型可能同时压低两者的概率来凑差值。

上一张卡片看到探索被砍。现在把 DPO 的账算全：三条缺陷，第三条（chosen 概率下降）最反直觉。

可以把这类比成一场比赛：DPO 只要求「冠军必须比最后一名高」，却不要求冠军自己「够快」——选手们可能一起跑慢，只要差距拉开，损失照样下降。

🧮 chosen 概率下降：损失在降，chosen 的绝对概率却跌破参考模型
Step 1：从训练开始到某个检查点的概率变化（示意）
回答参考 π_ref训练开始（π=π_ref）某检查点变化
chosen（π_w）0.30.30.25跌破参考
rejected（π_l）0.40.40.05掉得更狠
Step 2：log-ratio 差反而变大（β=0.1）
时刻d = log(π_w/ref_w) − log(π_l/ref_l)L = −log σ(β·d)
训练开始log(0.3/0.3) − log(0.4/0.4) = 00.693
某检查点log(0.25/0.3) − log(0.05/0.4) = −0.182 + 2.079 = 1.8970.603
损失从 0.693 降到 0.603，但 chosen 的绝对概率从 0.3 掉到 0.25、跌到参考模型之下——模型反而更少说「好话」了。原因：损失只看相对差、不看绝对值，模型可以靠「把 rejected 压得更狠」过关。

6
DPO 的 β 失效、chosen 概率下降、依赖参考模型这几条缺陷，后来的变体分别改了损失的哪一项？
提示：先想每个缺陷要「改损失的哪一项」才能补；再看是不是每个变体都正好对应一条缺陷。
▾
知识背景
DPO 之后出现一批变体：IPO（Azar et al., arXiv:2310.12036）指出偏好确定或接近确定时 DPO 会把概率推到 0/1、完全忽略 KL 正则（β 失效、过拟合），改用平方损失让正则重新起作用；DPOP（Smaug, Pal et al., arXiv:2402.13228）针对 chosen 概率下降，加一项「chosen 跌破参考就罚」；KTO（Ethayarajh et al., arXiv:2402.01306）只需单个回答的好坏、不需配对，处理「无偏好对」数据；CPO（Xu et al., arXiv:2401.08417，机器翻译论文）针对 DPO 要同时跑参考模型导致的显存翻倍与速度变慢，去掉参考模型，并加正例 NLL（行为克隆正则）防止偏离优选数据分布；ORPO（Hong et al., arXiv:2403.07691）把 SFT 和偏好合成一个目标、删掉参考模型；SimPO（Meng et al., arXiv:2405.14734）用序列平均对数概率（长度归一）+ 目标奖励差 γ、也删掉参考模型。第 40 课展开 IPO / KTO / CPO / ORPO / SimPO，DPOP 只在本卡提及。

上一张卡片列了三条缺陷。好消息是：每条缺陷都有变体针对，但并不是一个变体正好补一条。

可以把这类比成修车：DPO 是一辆「够用但有几处小毛病」的车——换减震（IPO 让 β 重新起作用）、加护栏（DPOP 防 chosen 概率下跌）、拆备胎（CPO/ORPO/SimPO 删参考模型）；KTO 则换了一种燃料（单条好坏标签）。
